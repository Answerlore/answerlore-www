# answerlore.com

The public Answerlore marketing site. Three static pages, no build step, no framework.

| File | Page |
|---|---|
| `index.html` | Home |
| `why-it-refuses.html` | Why it refuses |
| `pricing.html` | Pricing |

`CNAME` binds the site to answerlore.com. Do not delete it.

## Where the design came from

These pages were split out of the review mockup board at
`answerlore/answerlore-site/mockups/artifact.html` (private repo) on 2026-08-24.
That board is design history. **This repo is now the source of truth for the live site.**

## To change the site

1. Edit the HTML file.
2. Commit and push to `main`.
3. GitHub Pages redeploys within about a minute.

## Known gaps

- Secondary nav links (How it works, Resources, For service companies, For dealers,
  Your data, For owners) point at `#`. Those pages are not written yet.
- Every call-to-action button points at `#`. There is no trial signup or booking link yet.
